# JSP-000391 Formalization

Standalone Lean 4 verification repository for **JSP-000391** (Erdős Problem #482).

## Problem Description
Can the specified floor recurrence generate the digits of an algebraic number in a prescribed base?

## Mathematical Background
Erdős asked whether the sequence generated by $a_1 \ge 1$ and $a_{n+1} = \lfloor \sqrt{2a_n(a_n+1)} \rfloor$ satisfies that $\sum_{n=1}^\infty (a_{2n+1} - 2a_{2n-1}) 2^{-n}$ is algebraic.
Graham & Pollak (1970) and Stoll (2005, 2006) investigated this and related floor recurrences, proving that the Graham–Pollak recurrence $a_1 = 1, a_{n+1} = \lfloor \sqrt{2} (a_n + 1/2) \rfloor$ exactly produces the canonical binary digits of $\sqrt{2}$, an algebraic irrational number, and Stoll established the general normalized real binary expansion for all $t \in [1, 2)$.
